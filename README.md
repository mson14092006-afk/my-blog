<h1>Flask Blog DevOps Project</h1>
A production-ready Flask Blog application deployed on AWS EC2 using Docker Compose, automated CI/CD with GitHub Actions and Ansible, and secured with Nginx, Let's Encrypt, and DuckDNS.

<h2>Tech Stack</h2>

| Category | Technologies |
|----------|--------------|
| Backend | Flask, Gunicorn |
| Database | PostgreSQL |
| Database Migration | Flask-Migrate, Alembic |
| Containerization | Docker, Docker Compose |
| CI/CD | GitHub Actions |
| Automation | Ansible |
| Reverse Proxy | Nginx |
| SSL | Let's Encrypt |
| Cloud | AWS EC2 |
| DNS | DuckDNS |
